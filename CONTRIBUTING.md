# Contributing to frozi.lol docs

Thanks for helping improve the documentation.

## How to contribute

1. **Fork the repo** (or clone it if you have write access).
2. **Create a branch** for your change, e.g. `docs/fix-api-keys-page`.
3. **Edit the docs** in the relevant section of the repo.
4. **Preview locally** with `mint dev` and check your changes at `http://localhost:3000`.
5. **Open a pull request** with a short description of what you changed.

## Tips

- **API reference**: Keep endpoint MDX in sync with the OpenAPI spec; the `openapi` frontmatter must match the spec.
- **Preview before submitting**: Run `mint dev` and click through your changes to avoid broken links or missing pages.
- **Small PRs** are easier to review — one topic (e.g. “fix API keys steps” or “add leaderboard example”) per PR is ideal.

If you’re unsure where something belongs or how to phrase it, open an issue and we can figure it out together.

## Contributor badge

If your contribution is accepted and we consider it a useful change, you can contact us to receive a **free contributor badge** on your frozi.lol profile. The badge is not given for every edit; it is reserved for more significant contributions, such as adding new guides or improving large sections of the docs. Reach out via [Discord](https://discord.gg/ttURmxuR4T) or open an issue and we’ll get you set up.
