## What’s in these docs

- **Guides** — How to use frozi.lol (profiles, dashboard, links, and more). We’re adding guides over time; contributions are welcome.
- **API reference** — For developers: [getting started](/api-reference/introduction), [API keys](/api-reference/api-keys), [authentication](/api-reference/authentication), and [endpoints](/api-reference/endpoint/leaderboard) for leaderboard and profile lookup.

## Contribute to the docs

These docs are meant to cover the **whole app**, not only the API. If you want to add or improve a guide (e.g. how to set up a profile, use the dashboard, or manage links), we’d love your help.
