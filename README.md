# frozi.lol documentation

This repository contains the documentation and API reference for [frozi.lol](https://frozi.lol). It covers guides, API keys, authentication, and all public endpoints. The site is built with [Mintlify](https://mintlify.com).

**Live docs:** [docs.frozi.lol](https://docs.frozi.lol)

## Run locally

```bash
npm i -g mint
mint dev
```

Preview at `http://localhost:3000`.
